把手机上的重复操作
写成 auto(); 一样的脚本

Autox.js 是运行在安卓设备上的 JavaScript 自动化工具：靠系统无障碍服务读写界面、执行点击与滑动，大部分功能不需要 Root。写几行代码，就能让打开应用、找按钮、点确认这类机械动作自己跑起来。

Features

一台手机就是一套自动化开发环境

从写脚本、跑脚本到调脚本，它把整条链路都装进了一个应用里，不依赖电脑也能完成大半工作。

A11y

无障碍驱动，免 Root

通过系统无障碍服务读取屏幕控件、执行点击与滑动，常规自动化场景无需获取最高系统权限。

UI

控件与坐标两种定位

普通界面按文字、ID 精准找到控件再操作，换机型不容易错位；游戏画面等控件缺失的场景再退回坐标点击。

Img

找色、找图与文字识别

截屏之后可以按颜色定位按钮、按模板小图匹配目标，v7 分支还内置了 OCR 模型，屏幕上的文字也能读出来。

Rec

悬浮窗录制动作

打开录制后正常使用手机，点按与滑动会被记录成脚本代码，回放即可复现，是理解自动化写法的直观入口。

VS

连电脑协同开发

支持与桌面端编辑器联动：手机上写代码费劲时，把脚本投到电脑那边改，保存即同步，效率高一截。

Apk

脚本打包成独立应用

写好的脚本可以连同图片资源一起打包成单独的安装包，分给同样需要这套流程的人直接使用。

第一个脚本只要五行

内置编辑器带代码补全与格式化，脚本默认存在手机内置存储的「脚本」文件夹，文件管理器里就能直接看到这些 .js 文件。

  • 提示、启动应用、等待、按键，四个最常用的动作各占一行
  • 等待尽量写成「等条件成立」而不是写死秒数，网络慢也不点空
  • 跑飞了随时按音量上键停止，或点悬浮条上的停止按钮
main.js
// 弹出提示气泡
toast("脚本开始运行");

// 打开系统设置
launchApp("设置");

// 等待 2 秒（毫秒）
sleep(2000);

// 回到桌面
home();

FAQ

常见问题

需要把手机 Root 之后才能用吗？

常规的界面自动化走系统无障碍服务，不需要 Root。只有少数涉及更高系统权限的操作才有额外要求，日常写脚本可以完全不管。

它和老的 Auto.js 是什么关系？

Auto.js 原项目多年前已停止维护，社区在其基础上继续维护并发展出现在的 Autox.js，分成 6.x 与 7.x 两条分支：6.x 资料与教程最多，7.x 换了新界面并引入 Node.js 引擎、支持 TypeScript。两个分支的包名不同，可以同时装在一部手机上。

完全没写过代码，能上手吗？

可以先从悬浮窗的「录制」功能开始：正常操作手机，动作会被记成脚本，回放即可复现。看懂录出来的代码再照着改，是最平滑的入门路径；内置文档与应用商店里的示例代码也能直接跑。

什么系统版本能装？

近几年的主流安卓机型都可以。个别系统特别老的设备可能被安装器直接拒绝，这类情况只能换新一些的系统再试。
